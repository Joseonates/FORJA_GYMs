# FORJA

App para gimnasios: panel del dueño (panel.html), app de miembros (app.html) e inicio de sesión (index.html), conectados a Firebase.

Instrucciones completas de instalación en **LEEME.pdf**.

- `js/firebase-config.js`: pega aquí los datos de tu proyecto de Firebase.
- `firestore.rules`: reglas de seguridad; cópialas en Firestore → Reglas.
- `.github/workflows/firebase-hosting.yml`: publicación automática en Firebase Hosting.
